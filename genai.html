Data Ingestion: Tokenization & Embeddings

AI doesn't read words; it reads numbers. We first break text into chunks called Tokens, then map them to high-dimensional vectors called Embeddings.

Tokenization Process

"Generative" → [4532, 891]

Words are split into sub-words and assigned unique numerical IDs from a vocabulary dictionary.

Mathematical Representation

The formula maps a token index $i$ to a continuous vector space $E \in \mathbb{R}^{d_{model}}$:

$$x_i = E(token\_id_i) + PE(i)$$

PE (Positional Encoding): Adds sequence order information since models process all words simultaneously.

2

The Core: Multi-Head Self-Attention

This is the engine of Gen AI. Self-attention allows the model to weigh the importance of different words in a sentence relative to each other, understanding context and semantics.

Query (Q)

"What am I looking for?"

The current word asking for context from other words.

Key (K)

"What do I contain?"

The labels/descriptions of all words in the sentence.

Value (V)

"What is my actual meaning?"

The core semantic representation of the word.

Scaled Dot-Product Attention Formula

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
3

Inference: Predicting the Next Word

After processing context, the model passes data through a Feed-Forward Network and finally uses a Softmax function to calculate the probability of the next word.

Softmax Equation

$$P(y_i) = \frac{\exp(z_i / T)}{\sum_{j} \exp(z_j / T)}$$
