1. Conv2D Layer

Workflow: The network extracts local spatial features (like edges, textures) from the input image.

Mechanism: A parameter matrix called a Kernel or Filter slides across the input. At each position, it computes the element-wise dot product.

2. BatchNorm
& 3. ReLU

BatchNorm Workflow: Stabilizes and accelerates training by re-centering and re-scaling the feature map to have a mean of 0 and standard deviation of 1.

Z = (X - μ) / σ

ReLU Workflow: Introduces non-linearity. Without it, the entire CNN would just be a linear regression model. It simply drops negative values.

f(x) = max(0, x)

Tensor State (3x3)

4. MaxPool2D

Workflow: Performs spatial downsampling. It reduces the spatial dimensions (height & width) of the input volume for the next convolutional layer.

Benefits: Reduces computational load, memory usage, and the number of parameters (helping to prevent overfitting). It also provides basic translation invariance.

5. Dense Classifier
& 6. Softmax

Flatten: The 2D pooled tensor is unrolled into a contiguous 1D array to feed into the dense network.

Dense (Linear): Computes the raw scores (logits) mapping the features to the desired output classes using weights and biases.

Z = (W · X) + b

Softmax: Normalizes the logits into a valid probability distribution (all values sum up to 100%).

P(i) = e^(z_i) / Σ e^(z_j)
