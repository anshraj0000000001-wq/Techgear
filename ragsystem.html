How RAG Actually Works

Retrieval-Augmented Generation gives AI models a custom memory. Explore the architecture step-by-step.

Phase 1: Knowledge Preparation

Document Chunking

Before an AI can search your documents, they must be broken down into digestible pieces called chunks. Language models have a limited "context window" (amount of text processed at once).

Key Concept: Overlap

Chunks usually overlap by 10-20% to ensure context isn't lost if a sentence is split right down the middle.

"Machine learning algorithms build a model based on sample data, known as training data, in order to make predictions or decisions without being explicitly programmed to do so. These algorithms are used in a wide variety of applications, such as in medicine, email filtering, speech recognition, and computer vision."

Phase 2: Vectorization

Generating Embeddings

Computers don't understand words; they understand numbers. An Embedding Model transforms text chunks into high-dimensional arrays of floating-point numbers (vectors) representing semantic meaning.

Vocab Size 50,257

The total number of unique tokens (sub-words) the model's tokenizer knows. Text is converted to IDs from this vocabulary before vectorization.

d_model (Dimensions) 1536

The size of the resulting vector array. Each dimension represents a learned semantic feature (e.g., OpenAI's text-embedding-3 uses 1536).

Phase 3: Similarity Search

Finding Relevant Context

When a user asks a question, it is also embedded into a vector. The system queries the Vector Database to find document chunks pointing in a similar mathematical direction as the question.

Cosine Similarity

Calculates the cosine of the angle between two vectors. 1 = identical, 0 = unrelated, -1 = opposite.

$$ \text{similarity} = \cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}} $$

Phase 4: Augmentation & Generation

The Final Prompt

The retrieved chunks are injected into a prompt template alongside the user's original query. This combined prompt forces the LLM to ground its answer in your data.

Augmented Prompt

System: You are a helpful assistant. Answer the question based ONLY on the provided context.

Context (from DB):
"Machine learning algorithms build a model based on sample data, known as training data, in order to make predictions or decisions..."

User Query:
