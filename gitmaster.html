Git Commands Master Guide

Your ultimate A to Z cheat sheet for Git with explanations and examples.

1. Setup & Initialization

git config
Sets configuration values for your user name, email, gpg key, preferred diff algorithm, file formats and more. This is essential for tracking who made the commits.
# Set your username globally
git config --global user.name "John Doe"

# Set your email globally
git config --global user.email "johndoe@example.com"
git init
Initializes a brand new Git repository and begins tracking an existing directory. It adds a hidden .git subfolder within the existing directory that houses the internal data structure required for version control.
# Navigate to your project folder and run:
git init
git clone
Creates a local copy of a project that already exists remotely (like on GitHub or GitLab). The clone includes all the project's files, history, and branches.
# Clone a repository using its URL
git clone https://github.com/user/repository.git

2. Staging & Committing

git status
Shows the status of changes as untracked, modified, or staged. It helps you see what is going on with your files before you commit them.
# Check the current state of your repository
git status
git add
Moves changes from the working directory to the staging area. This tells Git that you want to include updates to a particular file in the next commit.
# Stage a specific file
git add index.html

# Stage all changed files at once
git add .
git commit
Takes the staged snapshot and commits it to the project history. Combined with the "-m" flag, it lets you write a descriptive message explaining the changes.
# Commit with a short, descriptive message
git commit -m "Add login form styling"

3. Branching & Merging

git branch
Lists all the local branches in your repository. It can also be used to create a new branch or delete an existing one.
# List all branches
git branch

# Create a new branch named "feature-login"
git branch feature-login
git checkout / git switch
Used to switch between different branches in your repository. 'git switch' is the newer, more intuitive command dedicated specifically to switching branches.
# Switch to an existing branch
git switch feature-login

# Create a new branch and switch to it immediately
git checkout -b new-feature
git merge
Combines the history of independent lines of development (branches) into a single branch. Usually, you merge a feature branch into your main branch.
# First, switch to the main branch
git switch main

# Then, merge the feature branch into main
git merge feature-login

4. Remote Repositories

git push
Uploads local repository content to a remote repository. It transfers commits from your local branch to the corresponding remote branch.
# Push local commits to the remote "origin" on branch "main"
git push origin main
git pull
Fetches and downloads content from a remote repository and immediately updates the local repository to match that content. It is essentially a combination of 'git fetch' and 'git merge'.
# Get the latest changes from the remote server
git pull origin main

5. History & Undoing

git log
Displays the entire commit history for the repository. You can see author details, dates, and commit messages.
# View full history
git log

# View history in a clean, single-line format
git log --oneline
git revert
Undoes a previous commit by creating a brand new commit that reverses the changes. This is the safest way to undo changes in public branches because it doesn't rewrite history.
# Revert a specific commit using its ID
git revert a1b2c3d
